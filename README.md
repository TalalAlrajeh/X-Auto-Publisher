# X Auto Publisher — نظام النشر المالي المجاني

نظام نشر آلي لحساب X عبر **GitHub Actions + Buffer Free**. يعتمد على مفتاح Buffer الموجود في GitHub Secrets؛ **لا يحتاج OpenAI API أو أي اشتراك توليد محتوى مدفوع**.

## المواعيد بتوقيت الرياض

07:30، 09:00، 10:30، 12:00، 16:00، 18:00، 20:00، 22:00.

- **الأحد–الخميس:** موضوعات مالية تثقيفية متنوعة (تاسي، إفصاحات الشركات، الأسواق الأمريكية، الذهب، النفط، الفائدة، الصناديق).
- **16:00:** محتوى هيئة السوق المالية. يفضّل القرارات والإعلانات المؤرخة الموثقة التي أُدخلت يدويًا، ويفرق بين القرار المعتمد ومشروع اللائحة المطروح لاستطلاع الآراء؛ عند انتهاء الأخبار الموثقة يستعمل مادة تنظيمية تثقيفية.
- **20:00:** تحليل **سهم محدد** في سلسلة تغريدات ضمن خانة النشر الواحدة. يحاول النظام أولًا بناء تحليل رقمي لسهم أمريكي من قائمة محددة اعتمادًا على بيانات SEC الرسمية (قوائم 10-K المقارنة) وبيانات إغلاق Stooq غير اللحظية (متوسط 20 و50 جلسة ونطاق 20 جلسة). يوضح تواريخ البيانات، الأرباح والإيرادات والتدفق النقدي والالتزامات والأصول، وماذا تعني مستويات الحركة بصورة شرطية دون توصية. إذا تعذر تأكيد أي مصدر أو كانت البيانات قديمة، يستخدم سلسلة عن **شركة سعودية مسماة**: تتضمن أرقامًا فعلية من الإفصاحات الرسمية لأرامكو وSTC ومصرف الراجحي للنصف الأول/الربع الثاني 2026 ما دامت خلال 120 يومًا من تاريخ نشرها، مع شرح المركز المالي وعوامل الأداء. أما الشركات التي لا تتوافر لها بيانات موثقة فيستخدم معها تحليلًا نوعيًا معلنًا بوضوح. **لا يخترع قيمًا أو مستويات سعرية**.
- **الجمعة والسبت:** منشورات DueNox فقط، من ميزات النظام المعلنة.

## اختيار الهاشتاقات

يستخدم هاشتاقات مرتبطة فعلًا بموضوع التغريدة ورمز السهم. في المحتوى المالي وتحليل الأسهم، يحاول قراءة خدمة Google Trends RSS المجانية لاتجاهات البحث في السعودية، ولا يضيف وسمًا جديدًا إلا إذا تطابق موضوع التغريدة مع مصطلح بحث رائج بالفعل، ولا يدّعي أن الهاشتاق رائج على منصة **X** دون بيانات مستقلة منها. إذا تعذرت القراءة، يستمر بالهاشتاقات الموضوعية. لا تُستخدم اتجاهات سياسية أو غير ذات صلة.

## حماية النشر

- كل عنصر في سلسلة X لا يتجاوز 280 حرفًا. يستخدم Buffer خاصية `metadata.twitter.thread` لنشر الأجزاء مترابطة.
- التنفيذ كل 20 دقيقة لفحص خانة تقع خلال 10–45 دقيقة؛ يُنشئ **منشور Buffer مستقبليًا واحدًا**، ثم يتولى Buffer النشر في الوقت المحدد. لا يُنشئ صورًا.
- فحص سجل Buffer يمنع وجود منشور ثانٍ في خانة واحدة ويمنع تكرار النص خلال مدة الحماية. لا يعيد الإنشاء آليًا إذا لم يستطع تأكيد نتيجة طلب Buffer.
- إذا ظهرت حالة فشل في GitHub يفتح Issue للتنبيه. لا توجد ضمانة 100% لتوافر GitHub أو Buffer أو X.
- لا يُنشر التحليل الرقمي إذا كان تاريخ بيانات السعر قديمًا أو كانت القوائم السنوية المقارنة غير مكتملة.
- **التحليل ليس استشارة أو توجيهًا استثماريًا.** لا توصيات شراء أو بيع، ولا أرقام غير مثبتة.

## متطلبات الإعداد — GitHub Secrets and variables

[افتح إعدادات المشروع](../../settings/secrets/actions) وأضف العناصر عبر واجهة GitHub فقط؛ **لا تحفظ المفاتيح في المستودع العام**.

| النوع | الاسم | الوصف |
|---|---|---|
| Secret | `BUFFER_API_KEY` | مفتاح Buffer API الخاص بك |
| Variable | `BUFFER_CHANNEL_ID` | معرّف قناة X |
| Variable | `BUFFER_ORGANIZATION_ID` | معرّف المؤسسة في Buffer |
| Variable | `PUBLISH_ENABLED` | `true` لتفعيل النشر، أو `false` للتوقف |
| Variable | `SEC_CONTACT_EMAIL` | اختياري: بريد اتصال عام تُستخدم قيمته ضمن User-Agent وفق قواعد الاستخدام العادل لـSEC، **وليس مفتاحًا سريًا** |

**لا تحتاج إلى `OPENAI_API_KEY`.** خدمة SEC API مجانية ولا تحتاج مفتاحًا، **لكنها أعادت HTTP 403 من خوادم GitHub في اختبار 4 أكتوبر 2026**؛ لذلك فالتحليل الأمريكي الرقمي غير مضمون حتى يوجد مصدر بديل مسموح وموثوق. خدمة Stooq غير مضمونة وقد تغيّر قيود التنزيل. لا يعتمد النظام على نجاح أي منهما لنشر معلومات غير مؤكدة. إذا أصبحت واجهات المصادر مقيدة بمفتاح أو مقابل مادي، لا تتجاوز تلك القيود.

## اختبار النظام

[GitHub Actions](../../actions/workflows/publish.yml) يشغّل `node --check` و`node --test` في كل تشغيل. عند تعديل الملفات، يشغّل اختبارات آمنة والاتصال للقراءة فقط دون نشر جديد؛ النشر الفعلي من المشغلات المجدولة عندما يكون `PUBLISH_ENABLED=true`.

اختبار محلي باستخدام Node.js 22:

```bash
node --check src/publisher.mjs
node --check src/stock-analysis.mjs
node --test tests/*.test.mjs
```

**حدود النظام:** التغطية الآنية للأخبار وقرارات الهيئة الجديدة ليست مكتملة بعد؛ القرارات المعتمدة في الكود تُضاف عند التحقق منها. لا توجد بيانات اتجاهات هاشتاقات X مجانية موثوقة موصولة تلقائيًا. نجاح اختبارات الكود لا يحل محل التحقق من المنشورات بحالة `sent` على Buffer وظهورها فعليًا على X.
