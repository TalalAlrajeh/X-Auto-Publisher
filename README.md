# X Auto Publisher

نظام مستقل لنشر تغريدات X عبر **GitHub Actions + Buffer API** دون الاعتماد على تشغيل مهمة ChatGPT عند كل موعد.

**الحالة الأولية: النشر معطّل**؛ لا يُرسل أي منشور ما لم تضبط متغير `PUBLISH_ENABLED=true`. المشروع لا يحتوي على كلمات مرور أو مفاتيح API.

## المواعيد والمحتوى

الأوقات بتوقيت الرياض يوميًا: **07:30، 09:00، 10:30، 12:00، 16:00، 18:00، 20:00، 22:00**.

- الأحد إلى الخميس: محتوى مالي عربي محايد عن الأسواق السعودية والأمريكية والذهب والنفط والفائدة والصناديق، بناءً على خبر حديث من مصدر موثوق يُتحقق من عنوانه وتاريخه.
- الجمعة والسبت: رسائل متنوعة عن الميزات المعتمدة لنظام DueNox فقط.
- لا سياسة أو شائعات أو توصيات استثمارية، ولا صور، مع منع تكرار النصوص.
- يعمل GitHub Actions كل عشر دقائق ويُعد **المنشور القادم فقط** قبل موعده بـ10–45 دقيقة؛ يقوم Buffer بنشره عبر `customScheduled` في الموعد المقصود، ثم يتحقق التشغيل اللاحق من حالته. هذا يعني وجود منشور واحد منتظر عادةً داخل Buffer، ضمن حد الخطة المجانية.
- عند الشك في نتيجة طلب الإنشاء، لا يعيد النظام الطلب دون فحص Buffer؛ لتقليل خطر تكرار التغريدة. وعند فشل التشغيل يفتح تنبيهًا واحدًا في GitHub Issues.

## الإعداد المطلوب منك

افتح [Secrets and variables → Actions](../../settings/secrets/actions) وأضف العناصر التالية **داخل واجهة GitHub فقط**؛ لا ترسل المفاتيح في المحادثة ولا تضعها في المستودع.

| النوع | الاسم | الغرض |
|---|---|---|
| Secret | `BUFFER_API_KEY` | مفتاح Buffer API من إعدادات Buffer |
| Secret | `OPENAI_API_KEY` | مفتاح OpenAI API لتوليد محتوى الأيام المالية باستخدام web search؛ **له تكلفة منفصلة** عن اشتراك ChatGPT |
| Variable | `BUFFER_CHANNEL_ID` | معرّف قناة X في Buffer |
| Variable | `BUFFER_ORGANIZATION_ID` | معرّف المؤسسة في Buffer |
| Variable | `OPENAI_MODEL` | اختياري: `gpt-5-mini` افتراضيًا، بشرط توفر الأداة `web_search` في حساب API |
| Variable | `PUBLISH_ENABLED` | اتركه `false` أولًا، وغيّره إلى `true` فقط بعد اختبار الاتصال |

اذهب إلى [Actions](../../actions) ثم اختر **X Auto Publisher** وشغّل **Run workflow**. يشغّل النظام `node --check` و`node --test` قبل كل محاولة، ومع `PUBLISH_ENABLED=false` لا ينشر مطلقًا.

بعد تجهيز المفاتيح ونجاح الاختبارات، أوقف مهمة ChatGPT القديمة للنشر على X قبل تمكين النظام الجديد لتجنب تشغيل نظامين على الحساب نفسه. أجرِ أول اختبار فعلي تحت المراقبة وتحقق من حالة `sent` في Buffer ومن ظهور المنشور في X.

## اختبارات محلية

يتطلب Node.js 22 أو أحدث، دون حزم npm إضافية:

```bash
node --check src/publisher.mjs
node --test tests/*.test.mjs
PUBLISH_ENABLED=false node src/publisher.mjs
```

## تنبيهات الاعتمادية والأمان

لا يمكن ضمان نجاح 100% بسبب اعتماد النظام على GitHub وBuffer وX ومصادر الأخبار. قد تتأخر تشغيلات GitHub، أو يتعذر التحقق من الخبر، أو يفشل X في النشر. النظام يتوقف عند النتائج غير المؤكدة ويُصدر تنبيهًا بدل نشر معلومة غير موثقة أو تغريدة مكررة.

المستودع **عام حاليًا**. يُفضّل تحويله إلى Private. لا تُضف أسرارًا إلى الملفات أو سجلات التشغيل. في المستودعات العامة قد يعطل GitHub الجداول بعد 60 يومًا من عدم النشاط.
